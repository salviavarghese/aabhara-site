Aabhara — jewellery catalogue site

Single-page catalogue site for Aabhara, a small jewellery business, built for their [Onam 2026 / launch] collection.

Live: https://aabhara.shop

What it does
- Shows the collection as a browsable catalogue
- One-tap ordering through WhatsApp
- Links to Instagram
- Open Graph tags so the link previews properly when shared on WhatsApp and Instagram

Stack
HTML, CSS, JavaScript. Deployed on Vercel with a custom domain (DNS and SSL set up by me).

What I did
- Designed and built the page
- Set up Vercel deployment, the custom domain, DNS records and SSL
- Made changes from the client's feedback after launch
